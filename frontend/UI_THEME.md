# AVSAR UI theme

## Visual direction
A clean opportunity-discovery marketplace that combines AVSAR's search-first landing page with the category-led browsing patterns people recognise from Unstop. Keep it approachable and practical; do not bring back the previous dark neo-brutalist treatment.

## Palette
- Main canvas: warm white `#f8faf7`
- Primary text: deep forest `#173326`
- Main action: bright leaf green `#b9ee63`
- Primary green: `#238754`
- Supporting surfaces: pale mint and sage
- Secondary accents: warm amber, peach and soft rose
- Avoid blue and purple accents.

## Design rules
- Use soft 10–18px radii for cards and controls.
- Use thin warm-neutral borders and restrained shadows.
- Prefer clear labels, readable body copy and visible metadata over decorative condensed typography.
- Opportunity cards must show category, organisation, location/compensation where available, deadline and trust status.
- Never represent a demo listing as verified, live or genuinely recommended by an AI score.
- Use responsive category grids: six columns on wide screens, four on medium desktop, two on compact screens.
- Keep interactive controls keyboard accessible and label icon-only actions.

## Ownership / integration
This document covers frontend presentation only. Keep API paths and response contracts in the shared `docs/` directory. Do not add browser-side secrets or direct Gemini calls to the frontend.
